STATUS: BLOCKED — NOT promoted. This file is a diagnostic, NOT L2 promotion evidence.

WHY BLOCKED
-----------
BackAttackYOffset_s_c is a REGISTER-OUTPUT routine. Its only observable outputs
are CPU register A and the NZVC flags:

    A_out = ram[$6CC0] ? (uint8_t)((~A_in) - 8) : A_in   (flags set accordingly)

The asm at $02:BB0B (PHA / LDA $6CC0 / BEQ / PLA / EOR #$FF / SEC / SBC #$08 /
RTS ...) writes NOTHING to WRAM — it only PHA/PLA on the stack (balanced) and
leaves the result in A.

translator/generate_spike.py can only compare WRAM: a fixed `output_ram` slot
or `SPIKE_COMPARE: region` (whole-WRAM memcmp, stack-masked). It has NO
register-output comparison path (verified: the Contract dataclass and parser
know only `output_ram`; there is no `output_reg`). With `output_ram: none`, the
generator emits the fallback comparison:

    uint16_t out_asm = 0; (void)snes;   // line 211 of the generated spike
    ...
    uint16_t out_c   = 0;               // line 222
    bool ok = (out_asm == out_c);       // 0 == 0 -> ALWAYS true

So the run below reports `fails: 0` while comparing two hardcoded zeros. It runs
the real asm and the real C, but observes neither's output. Promoting D02BB0B to
L2 on this would be a FALSE L2 — exactly what SKILL.md point 5 / "What NOT to do"
and prompts/reverser_system.md Pitfall 16 forbid.
